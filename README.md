# 台股 0050 / 正2 合理價估算

輸入目前大盤點數，自動推算 0050、00631L、00685L 的預估價，並顯示與最新市價的折溢價。

## 計算方式

| 標的 | 平均比例天數 |
|------|--------------|
| 0050 | 近 **240** 個交易日 |
| 00631L、00685L | 近 **2** 個交易日 |

- **預估價** = 你輸入的大盤點數 × 對應平均比例
- **比例** = ETF 還原收盤價 ÷ TAIEX
- **合理價（理論）** = 最新收盤市價（代理；實務上應參考淨值 NAV）
- 資料來源：Yahoo Finance Adj Close（已還原分割）
